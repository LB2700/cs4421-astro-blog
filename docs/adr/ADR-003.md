# ADR-003: Use AWS SES for Supabase Auth email

- **Status:** Pending
- **Date:** 2026-10-20

## Context

Supabase Auth sends signup confirmation and other account emails. The default email service is restricted and intended for development, so the project needs a separate SMTP provider to deliver messages to users.

## Decision

Use Amazon Simple Email Service (AWS SES) as the SMTP provider for Supabase Auth.

Configure SES SMTP credentials and the verified sender address in Supabase's SMTP settings. Keep SMTP credentials in Supabase configuration, not in the application or its environment files.

## Consequences

- SES integrates with Supabase Auth through standard SMTP and keeps email delivery separate from application runtime code.
- The project must manage SES region selection and sending limits,
